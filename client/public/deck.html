Why today's tools fail

A confident answer you can't verify is worse than no answer.

Generic chatbot

Ownership in Rust means each value has a single owner and is dropped when the owner goes out of scope. Borrowing rules were relaxed in the 2021 edition to allow…

Answered from the open internet. Which edition? Which page? Is that last clause even true? The night before an exam, the student cannot check — and it isn't in their syllabus anyway.

Manthan

Each value in Rust has a single owner; when the owner goes out of scope, the value is dropped [1]. A move transfers ownership rather than copying [2].

[1] The Rust Book — PDF, p.68 · [2] Lecture 4: Memory — YouTube, 12:41

Every claim is retrieved from the student's own uploaded sources, and each citation opens the exact passage. Nothing scored below the similarity floor gets into the prompt.

Retrieval enforces a hard floor: chunks below 0.35 cosine similarity are dropped rather than padded into the prompt to manufacture an answer. Manthan would rather say it doesn't know.

05

The product

Pour in, churn, draw out.

Samudra Manthan: the ocean was churned to draw out amrit. Same mechanic — raw sources go in, understanding comes out. The three steps are the actual pipeline, not a metaphor.

01

Pour in the sources

PDF (page-aware), any website via Firecrawl, YouTube transcripts, pasted text and markdown. Ingestion runs as a background job, so a 300-page book doesn't block the UI or die on a refresh.

02

Let the rope turn

Recursive chunking at 1,000 characters with 100 of overlap, page numbers carried in metadata, embedded and indexed into a per-workspace vector namespace. Retrieval happens over passages, and every passage keeps its address.

03

Draw out the nectar

Ask and get a streamed, cited answer. Or turn the same indexed material into a summary, key takeaways, flashcards, an MCQ quiz with explanations, a mind map, or a long-form report.

It remembers the learner

Long-term memory keeps your goals, exam date and weak topics across every workspace and every session — not just the current thread.

Long threads stay coherent

A rolling summary is generated every 8 messages, so a 200-message revision thread stays both cheap and on-topic.

Web search, off by default

A per-message toggle for when the sources genuinely don't cover it — deliberately opt-in, so grounding is the default state.

07

Under the hood

A real pipeline, not a prompt.

Ingest

  • Text extraction: unpdf (page-aware) · Firecrawl · youtube-transcript
  • Recursive splitter over ["\n\n", "\n", ". ", " ", ""] — 1,000 chars, 100 overlap
  • text-embedding-3-small, 1,536 dims, upserted into a per-workspace namespace
  • Durable background jobs with retries — the UI never waits on a 300-page book

Answer

  • Workspace ownership checked on every single request
  • Top-6 retrieval, hard floor at 0.35 similarity
  • Prompt = rules + user memories + rolling summary + numbered chunks + optional web results
  • Streamed to the browser; message and citations persisted after
  • Model whitelisted server-side — a client can never name its own model

Founder time unpaid. Fixed infra is ~₹7,100/month, so 90 paying users cover the servers and ~350 cover a modest founder salary — reachable around month five on the funnel above.

Seven levers on model & infra cost

  • Route by difficulty. Escalate to gpt-4o only when retrieval scores are weak or the user asks. Cuts the largest line item by more than half
  • Prompt caching on the system block and repeated source chunks — cached input is half price
  • Batch embeddings. Ingestion is already async, so latency doesn't matter and the batch tier is 50% off
  • Embed shared sources once. Five hundred students on the same NCERT chapter should not each pay to index it
  • Semantic answer cache across users for identical public sources — one class asks the same chapter question 200 times
  • Dedupe artifacts by source-set hash: same sources + same type = reuse, don't regenerate
  • Open-weight models for flashcards and summaries once volume justifies the serverless GPU

Getting users

Go where the syllabus already lives.

1 · Founder-led content, Instagram first

“I fed my entire GATE syllabus to an AI and it quizzed me back.” Build-in-public reels on the product, the problem and the failures. The demo is the ad — the citation opening on page 291 is the hook.

2 · Seeded exam communities

Telegram and Discord groups for GATE, UPSC and NEET. Drop in a ready-made public workspace pre-loaded with that exam's standard source pack. Value before signup.

3 · Campus ambassadors

One per college: free Scholar, plus ₹100 per paid referral. Students trust a senior who is visibly using it more than any ad.

4 · Programmatic SEO that pays twice

Public pages for “<subject> chapter summary” and “<subject> flashcards”, generated from public source packs. They rank and they warm the semantic cache that cuts our own inference bill.

5 · Coaching institute pilots

Free for one batch for one cycle, in exchange for quiz-performance data. The teacher becomes the distribution channel for thirty seats at a time.

The wedge

Shared source packs

Every channel above pushes students onto the same textbooks. That concentration is what makes caching, shared embeddings and institute margins work. Distribution and unit economics are the same strategy.

Roadmap

From “understands my syllabus” to “knows how I forget”.

Next 3 months

Close the study loop

  • Spaced repetition on flashcards (SM-2), scheduled against the exam date
  • Exam mode — timed mock tests generated from the whole workspace
  • Audio overview: a two-host recap of a workspace for the commute
6 months

Make it theirs

  • Handwritten-notes OCR — the last unindexed source students actually have
  • Answers in Hindi and regional languages over English sources
  • Mobile PWA with offline flashcard review
12 months

Make it social, and smarter

  • Shared workspaces for study groups
  • Institute dashboard: which chapters is the batch failing?
  • Weakness-aware retrieval — quiz results steer what gets surfaced next

The long game is a model of the learner, not just the library. Once Manthan knows which chapters you get wrong and when you forget them, the quiz that shows up on Tuesday morning is not a feature — it is the reason you stay subscribed.
